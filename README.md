# Barcelona Pavilion

[Open the interactive sunset scene](https://danielsxujiacong-cell.github.io/barcelona-pavilion/)

The browser renders the pavilion using WebGL2. Drag to orbit, scroll to zoom, and use Reset View to return to the original camera. Path tracing refines the picture when the camera stops moving.
